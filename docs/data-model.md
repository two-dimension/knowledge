# 数据模型与口径

## 核心对象

| 对象 | 含义 | 关键字段 |
| --- | --- | --- |
| Conversation | 一次完整交流 | 时间、地点、场景、参与者、授权、知悉范围 |
| Source | 信息源人物或匿名角色 | 领域、机构、关系、历史可靠度、敏感标签 |
| Artifact | 原始材料 | 录音、逐字稿、速记、文件哈希、保留期 |
| Chunk | 可检索原文片段 | 说话人、时间码、前后文、实体、embedding |
| SearchChunk | 当前轻量检索单元 | 谈话、类型、序号、内容、元数据、更新时间 |
| TranscriptionJob | 音频处理任务 | 上传文件、服务商、模型、状态、逐字稿、说话人片段、候选结构、错误 |
| Thesis | 研究观点 | 陈述、类型、方向、时间窗、置信度、状态、版本 |
| Evidence | 证据关系 | 支持/反对、直接/间接、来源、片段、权重 |
| Entity | 规范化实体 | 证券、公司、行业、指标、主题、别名 |
| Verification | 验证任务 | 指标、阈值、反证条件、负责人、截止、结果 |
| AuditEvent | 审计事件 | 谁、何时、对什么、做了什么、前后差异 |
| WikiPage | 编译后的 Markdown 知识页 | 类型、正文、双向链接、原始来源、健康度、版本、生成方式 |

## 陈述类型

- **事实 Fact**：已发生且原则上可独立核验。
- **观察 Observation**：信息源在有限样本中的直接观察。
- **观点 Opinion**：解释或判断，不天然可证伪。
- **预测 Forecast**：带时间窗和结果条件的未来判断。
- **传闻 Rumor**：未确认的转述，默认不进入回答主证据。

## 证据等级

1. A：直接决策人/执行人 + 原始材料 + 可独立核验
2. B：直接参与者口径，已有第二来源印证
3. C：单一来源的直接观察
4. D：二手转述或缺乏上下文，仅做线索

综合置信度应由信息直接性、来源历史可靠度、交叉印证、时效性和反对证据共同决定，不能由模型单独拍分。

## 生命周期

`draft → reviewed → tracking → verified / falsified → superseded → archived`

任何更新都创建新版本；旧版本保留当时的证据和上下文。观点到期但尚未验证时标记为 `stale`，不能继续以当前事实展示。
